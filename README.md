# bhoptools

rawinput2, real client-authoritative triggers, 0 ping checkpoints, 0 ping hud elements, like bhop-get-stats and more.
other fixes include viewpunch removal, 8k polling rate support, fps_max over 1k supported among a few others.

## installing

grab the latest build from [Releases](../../releases).

- windows: run `bhoptools.exe`.
- linux: run `./bhoptools` to get the launch options spat out.

## found a bug?

log it with bhoptools_log, this is a toggle so turn it on, reproduce, and turn it off.
send it to me on discord @ faskfjppois, the log lives in /cstrike bhoptools_log.txt
